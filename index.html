❓ 常見問題 FAQ

Q: 為什麼我進遊戲左下角麥克風圖示畫斜線 (🚫)？

A: 請確認你電腦裡是否有正確將 Voice Chat Mod 放入 mods 資料夾，或者嘗試按 V 鍵檢查輸入設備（麥克風）是否選擇正確！

Q: 大家都聽得到我講話嗎？

A: 這不是全服通話！只有在你身邊 48 格內 的玩家才聽得到你的聲音，並且聲音會根據距離遠近遞減，距離越遠聲音越小喔！

常用指令 Common Commands

熟悉伺服器基礎與懸賞指令，讓你的生存冒險更順手！

/tpa <玩家ID> 玩家傳送

請求傳送到該玩家身邊。

傳送時必須在原地靜止等待 5 秒，期間移動或受到任何傷害傳送會直接取消。
/tpaccept <玩家ID> 接受傳送

接受其他玩家向你發送的傳送請求。

/sethome 設定家

在你當前踩的位置設定一個「家」。

普通玩家限制最多只能設定 3 個家，請謹慎選擇蓋基地的地方。
/home 傳送回家

瞬間傳回你設定的家。

同樣需要原地等待 5 秒，戰鬥中受傷會打斷傳送。
/shop 系統商店

開啟伺服器官方商店選單進行購買（可買 PvP 物資、生怪籠等）。

特別注意：戰鬥中也可以使用 /shop！
/sellgui 物品販售

開啟販售物品介面。將要賣掉換錢的物品放入視窗內即可一鍵賣出。

/bounty set <玩家> <金額> 發布懸賞

懸賞捉拿一名玩家。成功擊殺目標的玩家將可獲得賞金！

/bounty remove <玩家> 取消懸賞

取消你對該玩家設定的懸賞金額（僅會獲得部分退款）。

/bounty list [頁數] 懸賞列表

查看全服所有目前有效的通緝賞金名單。

/bounty top 獵人排行

查看伺服器中最出色的頂級賞金獵人排行榜。

遊戲守則 Minecraft Server Rules

請全體玩家切實遵守，維護公平優質的遊戲環境。

🚨 核心禁止事項（觸犯將直接封禁）

伺服器配備自編反作弊偵測系統，請勿抱持僥倖心態以身試法！
  • 嚴禁使用外掛作弊端：禁止使用任何形式的作弊客戶端（如 Meteor、Wurst）。
  • 嚴禁移動類外掛：禁止使用修改移動速度、飛行、反擊退或非原版移動機制的模組。
  • 嚴禁背包與物品欄優化外掛：禁止使用會自動整理、自動抽取的背包相關外掛。
  • 嚴禁血量顯示輔助：禁止使用機能看見其他玩家或怪物精確血量的顯示功能。
  • 嚴禁雷達功能：禁止使用任何形式的玩家或小地圖雷達。
  • 嚴禁靈魂出竅自由視角：禁止使用 Freecam 自由視角功能。
  • 嚴禁透視功能：禁止使用透視玩家、箱子、方塊或礦物的 ESP 功能。
  • 嚴禁自動便捷放置方塊：禁止使用自動放置方塊或任意角度強行放置方塊的功能。
  • 嚴禁巨集與腳本：禁止使用任何形式的自動化巨集軟體或按鍵腳本。
  • 嚴禁連點器：禁止使用任何形式的自動連點器。
  • 嚴禁滑鼠輔助滾輪優化：禁止使用 Mouse Tweaks 或利用滾輪快速移動物品等相關優化功能。
  • 嚴禁修改合成機制：禁止使用任何修改或加速原版合成邏輯的客戶端功能。

⚠️ 遊戲漏洞與公平性

  • 嚴禁惡意利用 Bug：禁止惡意利用遊戲內的任何漏洞、錯誤或異常機制。
  • 嚴禁嘗試與執行複製：任何嘗試尋找、測試或複製物品漏洞的行為皆不被允許。
  • 每人帳號上限為 5 個：同一位玩家在伺服器內最多只能使用 5 個不同的帳號。
  • 嚴禁查詢與使用地圖種子碼：禁止透過任何手段尋找、破解或利用本世界的地圖種子來搜尋結構與礦物。

💬 聊天室與社交規範 Chat Rules

  • 嚴禁惡意刷屏與廣告：禁止在聊天室發送重複訊息、煽動刷屏，或宣傳其他伺服器/商業連結。
  • 零容忍言語騷擾與歧視：禁止持續性言語騷擾、辱罵、霸凌，以及種族、性別、宗教等歧視言論。
  • 嚴禁死亡威脅與洩漏隱私：禁止發表人身安全/死亡威脅，以及公開、散布他人真實姓名、照片等個資。
  • 嚴禁假冒管理團隊：禁止假冒、自稱是工作人員或代表官方發言。
  • 嚴禁邀請/衝能欺詐與外部賭博：禁止偽造邀請獎勵、騙取 Discord Boost 獎勵，或進行外圍賭博。
  • 嚴禁語音音訊轟炸：禁止在近距離語音聊天中播放噪音、高分貝音樂或惡意刷屏。
  • 嚴禁惡意規避處罰：若帳號遭封鎖，嚴禁使用分身小號繞過處罰。
  • 主動回報義務：若發現任何 Bug 或作弊玩家，請務必第一時間回報管理團隊。

💡 管理團隊終極提醒 Use Common Sense

請保持基本的常識與理性！
